# INTENT-T16：灵感小铺泛命名（P1）

## 1. 背景与目标
引流与留存轻场景。目标：**网名/游戏ID/宠物名/笔名/角色名五场景即时生成 10 个，无姓氏、无深度报告**，承接韩系/日系等风格标签。

## 2. 范围
**做**：inspiration 页、场景切换、轻量生成（复用 generate 增 inspiration 模式）、轻结果展示。
**不做**：深度报告、收藏进选名夹主流程、共选（可收藏但独立轻列表）。

## 3. 输入
- PRD M6-1/6-2；Non-goals（韩/日系只进本模块）
- 交接包 generate 契约（扩展约束）、原型整体视觉（无独立屏，沿用卡片语言）

## 4. 产出
```
miniprogram/pages/inspiration/index.{js,wxml,wxss,json}
cloudfunctions/generate/lib/prompt-inspiration.js   # 轻量 prompt（无需姓氏，风格词表含韩系/日系）
cloudfunctions/generate/lib/solver-inspiration.js   # 泛命名解空间（白名单放宽至 8105 全表 + 可选非规范字开关仅限本模式）
```

## 5. 实现要点
- create 增 `mode:'inspiration'` 分支：跳过姓氏校验、固定 10 个候选、绕过典籍出处维度（quote 必为 null）、过滤流水线仍全量生效（红线/白名单按放宽集/谐音/SecCheck）。
- 场景与风格 chips 独立状态（`场景切换独立生效`，PRD 6-1），韩系/日系风格词表仅在此模式注册，宝宝起名主线不可达（Non-goals 隔离）。
- 即时生成目标 <5s（10 个、无出处校验），同步返回不走轮询亦可。
- 商业化：本模块不设付费墙（引流定位），仅展示 AI 横幅与免责。
- 埋点复用 generate_success（source:'inspiration'）。

## 6. 验收标准
- [ ] 五场景切换后生成结果与场景匹配且互不串状态
- [ ] 无姓氏输入可生成；输出 10 个；无深度报告入口
- [ ] 韩系/日系风格仅本模块可选，宝宝主线风格列表不含（代码断言）
- [ ] 过滤流水线对本模式全量生效（红线词 mock 用例通过）
- [ ] AI 横幅与免责正常展示

## 7. 依赖与风险
- 依赖：T04（模式扩展）、T05。
- 风险：放宽白名单引入生僻字输入法打不出的名字 → 非规范字开关默认关闭。

2.5
