# INTENT-T12：命名说明书生成导出（P1）

## 1. 背景与目标
长辈说服与家庭存档的终产物。目标：**把选中名字的典故原句、字义、音律、寄语排版为可保存/打印的长图文卡**，导出率目标 ≥10%。

## 2. 范围
**做**：说明书长卡生成（多段 canvas 拼接或分段长图）、可勾选章节、导出保存、转发。
**不做**：PDF 排版/服务端渲染（成本高，首版长图足够）；已付费墙逻辑由 T13 决定（P1 默认免费或深度包权益，随 T13 定稿）。

## 3. 输入
- PRD M4-3、用户故事 2/4
- 交接包 candidates quote/checks 字段、M5 字段白名单（同样适用）
- 原型屏04/05 的说明卡视觉

## 4. 产出
```
miniprogram/pages/report/index.{js,wxml,wxss,json}    # 说明书生成页（章节勾选+预览）
miniprogram/components/report-canvas/*                # 长图渲染（复用 poster-canvas 能力扩展）
miniprogram/utils/report-compose.js                   # 文案组装（原句/字义/音律/寄语模板）
```

## 5. 实现要点
- 章节结构：封面（名字+拼音+寄语）→ 典故（原句/作者/篇名，仅 verified）→ 字义逐字解析 → 音律（拼音+平仄说明文字）→ 书写（笔画）→ 尾部免责+AI 生成标识。
- 字段白名单与 T11 同规（复用 poster-fields.js），无生辰无父母全名。
- 长图超出 canvas 尺寸限制 → 分段绘制多张或降低缩放比拼接；目标高度上限 8000px。
- 导出同 T11：saveImageToPhotosAlbum + 转发；埋点 `report_share{type:'manual'}`。
- 文案模板独立文件，便于合规审查与迭代。

## 6. 验收标准
- [ ] 选中候选一键生成完整长图，章节可勾选增删
- [ ] 无 verified 出处时典故章节自动隐藏且不排版错乱
- [ ] 长图真机保存成功（iOS/Android 各一台）；图片含免责与 AI 标识
- [ ] 字段白名单校验通过；report_share 埋点上报

## 7. 依赖与风险
- 依赖：T09（选名夹数据）、T10（可从共选房间进入）、T11（canvas 基建）。
- 风险：长图内存峰值 → 分段渲染；P1 优先级，允许在 T11 稳定后启动。
