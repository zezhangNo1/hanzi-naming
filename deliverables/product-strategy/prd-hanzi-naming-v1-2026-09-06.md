# PRD：汉字美学 · AI 取名工具（微信小程序）

**日期**：2026-09-06
**版本**：v1.0（基于产品战略团队五份成员报告收口）
**状态**：待评审
**配套原型**：`prototype-hanzi-naming.html`（高保真，6 屏）

---

## 📌 TL;DR

- **产品定位**：「汉字美学 · 典籍取名」——彻底去玄学化的取名决策辅助工具。只讲字义、字形、字音、平仄音律、典籍出处、字辈避讳、重名度、方言与跨文化谐音、书写与政务系统兼容性；**零吉凶、零运势、零打分**。
- **核心差异化**：①方言谐音 + 跨文化发音歧义检测（竞品空白，窗口约 12 个月）②家庭共选决策辅助 ③可校验的典籍出处。
- **不做**：周易解梦、八字五行、名字打分/评分、塔罗签文、生肖运势（微信平台内容层红线，与主体性质无关）。

## 2. 用户故事（5 个场景）

1. **产后定名冲刺**：宝宝出生第 10 天，出生证办理窗口临近，新手妈妈在 3 天内需要敲定名字 → 打开小程序，输入姓氏 + 性别 + 风格偏好，10 秒内获得 30 个候选，收藏 5 个发家庭群。
2. **家庭共识仲裁**：爷爷奶奶坚持要"按辈分带'承'字"，夫妻想要现代感名字 → 使用"家人共选房间"，长辈可勾选字辈约束，全家对 8 个候选投票，系统生成一份《命名说明书》供全家存档。
3. **避坑检查**：爸爸心仪"诗婷"，但担心粤语谐音/英文歧义 → 名字详情页展示普通话、粤语（jyutping）、英语发音检测，提示 "Shiting" 歧义，给出同风格替代。
4. **长辈说服**：长辈问"这名字有什么讲究" → 详情页可展示《诗经·邶风》原句 + 字义 + 音律分析，一键生成可打印的命名说明书。
5. **泛命名轻场景**：用户想给新养的猫起个日系名字 → 切换到"灵感小铺"模式（网名/宠物名/笔名），即时生成，用于引流与留存。

## 5. 关键流程

### 5.1 首次起名流程

```
进入 → 首屏 3 项输入（姓氏/性别/风格）→ 点「开始取名」
  → 服务端：白名单字库筛选 → LLM 生成（8-15s，流式）→ 出处三元组校验 → 谐音/敏感词过滤
  → 结果列表（免费 2 批）→ 收藏进选名夹
  → [折叠卡] 可选补充：生辰（单独授权）/ 字辈 / 寄语 → 提升下一批精度
  → 免费额度用完 → 激励视频 +1 批 或 ¥9.9 深度包
```

### 5.2 家人共选流程

```
选名夹（3-8 个）→ 生成共选链接 → 分享家庭群
  → 家人打开 → 逐个点赞/踩 + 一句话理由 → 主用户收到票数汇总
  → 敲定 → 生成《命名说明书》→ 导出/打印/发群
```

### 5.3 质量兜底流程

```
LLM 输出 → ① 白名单校验（不在表内→丢弃重生成）
         → ② 出处三元组本地索引校验（不过→不展示出处）
         → ③ 红线词/谐音/敏感词过滤（命中→拦截重生成，记录拦截日志）
         → ④ msgSecCheck（双侧）
         → 全过 → 展示；任一环节 3 次失败 → 降级规则引擎输出
```

## 6. Non-goals（明确不做）

- ❌ 周易解梦、八字排盘、五行补缺、五格三才、名字打分/评分/测试、塔罗签文、生肖运势、手相面相、老黄历宜忌、改名改运 —— 内容层红线，任何主体都做不了。
- ❌ "韩系/日系"风格进入宝宝起名主线（与"长辈认可 + 能上户口"冲突，移入泛命名模块）。
- ❌ "父母性格"作为输入（伪需求，改为用户真会填的"期望寄语"）。
- ❌ 社区/UGC 广场（15.2.1 隐私展示风险 + 审核成本，首版不做）。
- ❌ 完整"家庭投票房间"体系（竞品已占心智，只做最小共选链接）。
- ❌ 重名查询直连公安系统（无 API、有频控；改为结果页放官方自查指引）。

## 7. 技术架构建议

- **主体**：个体工商户（注册 ¥0-500、1-3 工作日，与开发并行）。
- **技术栈**：原生小程序 + 微信云开发 CloudBase（云函数调用 LLM，API Key 不落前端）。
- **数据集合**：`users` / `name_jobs`（生成任务）/ `candidates` / `collections`（选名夹）/ `votes` / `orders` / `feedback` / `block_log`（拦截日志）。
- **本地词库**：通用规范汉字表白名单、康熙笔画/拼音声调库（开源）、粤 jyutping 映射、英语近似词表、不雅谐音词表、禁用词表、典籍语料索引（全唐诗/宋词/诗经/楚辞，公有领域）。
- **LLM**：中高端模型生成（Qwen Plus / DeepSeek V4 级）+ 低端模型粗筛；成本 ¥0.002-0.034/次，可忽略。
